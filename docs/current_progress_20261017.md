## 实测结果

同一服饰同款开发协议下：

| 策略 | Recall@10 | Precision@10 |
|---|---:|---:|
| 整图对照 | 78.12% | 35.77% |
| 多视图等权平均 | 78.09% | 35.77% |
| 查询与商品均多视图，加区域注意力 | 80.24% | 36.92% |
| 查询仅整图，商品多视图加注意力 | 80.56% | 37.31% |
| k互近邻重排 | 84.86% | 40.77% |
| k互近邻与区域注意力融合 | 85.41% | 41.15% |

全多视图注意力相对整图提升2.11个百分点召回、1.15个百分点精度；5条查询改善、1条退化、20条不变。查询编码加匹配P95约1.65秒，不含模型与索引加载。完整分项结果与失败案例见 [实验报告](module2_experiment_report.md)。

严格同款开发协议的平均Precision@10理论上限仅47.69%，该任务不能用于直接判定PDF的广义商品相关性Precision@10≥60%。三大品类正式人工相关性标注仍待完成，当前不声明正式验收达标或总体质量已超过要求。

## 下一步优先级

先在独立商品组上复核新组合，处理短裤子类和1条召回退化；单线程CPU评分P95约128毫秒，完整服务响应仍需另测。其次测试专用Cross-Encoder及混合召回，避免只增加策略数量。

1. **改善区域候选**：自动ROI只在334件候选中的37件产生有效候选，单独收益小。对复杂背景、广告字和小主体引入更好的检测／显著性候选，保留全图对照。
2. **独立评测**：为修订商品池建立真实相关性标注，分开评价文搜商品、图搜商品、局部查询；按商品组隔离开发与测试，不能把本次开发结果作为盲测。
3. **策略选择**：通过ROI、窗口、放大、查询视图、标题融合和属性排序消融选择组合，同时检查退化与开销。当前尚无单独“放大与不放大”的效果实验。
4. **学习型注意力**：训练集与评测集确定后，再训练轻量投影和区域门控，引入困难负例和对比学习。不能用测试标签辅助裁切或排序。
5. **交互与性能**：构建常驻检索模型的Demo，支持文本输入、上传图片、用户选框和结果解释；分别报告冷启动及预加载后的完整响应P50/P95。
