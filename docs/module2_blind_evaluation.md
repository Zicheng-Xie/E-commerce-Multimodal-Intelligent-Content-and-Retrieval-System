更新日期：2026年10月22日。旧服饰同款成绩全部用于过策略比较和开发，不能作为独立测试或正式验收结论。当前建立一份新的独立同款盲测，用于检验冻结候选在新商品组上的表现；正式三品类商品相关性验收另行准备。

## 本轮冻结协议

历史暴露快照为 `artifacts/module2_blind/exposure.json`，包含所有既有 `data/` 中JSONL文件的哈希、已准备样本ID、服饰pair组及图片指纹。清单覆盖1,728条记录、99个服饰pair组、648个商品源ID和1,690种图片文件内容。原始大库用于本轮建集的元数据扫描不会产生模型成绩；未记录的人为访问无法由本地清单认证。

先写入 `recipe.json` 和 `freeze_receipt.json`，再准备新数据。冻结内容包括实际模型权重及处理器文件的SHA256、相关代码、依赖版本、区域配置、互近邻参数、采样种子及样本量。之后如修改相关代码、参数、模型或已登记数据，预测与评分均拒绝继续。

| 固定项 | 本轮配置 |
|---|---|
| 对照 | 原整图余弦检索 `global` |
| 唯一待验证候选 | 旧开发阶段选出的 `reciprocal_attention_fusion` |
| 调参 | 不在本轮新数据上调参，也不重跑13种策略后取最大值 |
| 查询 | 仅原始整图，一次查询一个向量；不把其他评测查询加入邻域 |
| 商品 | 最多7个像素或固定几何区域，沿用旧区域配置；不读取源框或掩码 |
| 模型 | 本地Qwen3-VL-Embedding-2B，revision及实际文件哈希随协议封存 |
| 数据 | DeepFashion2源validation元数据全集32,153条；排除已暴露样本与原始数字pair_id |
| 抽样 | SHA256种子20261022；5个类别各8个不同pair查询组；400候选；不看模型分数选样 |
| 正例 | 冻结图库内源pair、style与类别一致的shop图，排除与查询相同的文件或解码像素 |
| 首要比较 | 查询组配对的Recall@10与完整排序mAP；正负变化均报告 |
| 其他观察 | Precision@10、NDCG@10、MRR、Hit@1、其他K值及暖态耗时；不据此另选策略 |
| 不确定性 | 1,000次商品组配对bootstrap的探索性95%区间；不能解释为总体达标保证 |

抽样限制于单件服饰user查询与有配对shop图的商品，五类均衡，不代表真实业务流量分布。未把新数据的源类别、pair或答案传入排序；匿名ID仅用于对齐和固定同分顺序。

## 泄漏与重复检查

旧记录ID与旧pair组全部排除。数字pair_id跨官方划分是否共享身份未经确认，本轮保守地跨划分排除相同数字。排除与旧图片相同的文件SHA256、EXIF校正后RGB像素哈希，以及64位dHash距离不大于4的风险样本。新盲测中的不同pair组也执行近似图像排查；图库去除相同文件与像素副本。

本轮得到40查询、400候选、245个pair组。已登记历史ID、pair组、文件及像素重叠均为0，未留下dHash阈值以内的历史风险样本。dHash用于筛查，不保证发现所有语义重复或商品同款；后续真实商品池仍需来源ID、SKU/商品族、标题、URL和人工复核相结合。

文件布局如下：

```text
artifacts/module2_blind/
  exposure.json                 历史暴露快照
  recipe.json                   冻结策略、模型、代码和数据规则
  freeze_receipt.json           冻结协议哈希
  dataset/public/gallery/       仅匿名ID及图片
  dataset/public/queries/       仅匿名ID及图片
  dataset/evaluator/qrels.json  评分答案，不传入模型
  dataset/evaluator/lineage.json 来源商品组与审计依据
  dataset/manifest.json         数据全部文件的哈希
  predictions/                  图库向量、完整排序、查询向量和耗时
  prediction_receipt.json       全部预测完成后封存的文件哈希
  score.claim.json              首次开封凭据，开封后数据已消耗
  internal_report.json          独立同款内部评分与全部逐查询结果
  public_status.json            可同步的状态，正式验收指标为null
```

这是同一账户下的逻辑隔离和可追溯流程，不提供账户权限隔离。真正的外部盲验收应由独立评测人保管答案，并在模型提交后运行评分。

## 一次性运行

在项目根目录的PowerShell执行。已生成的审计、冻结协议、数据集和开封凭据不可覆盖，不应为更换策略或获取更高分而删除。

```powershell
.\.venv312\Scripts\python.exe scripts\blind_retrieval.py audit
.\.venv312\Scripts\python.exe scripts\blind_retrieval.py freeze
.\.venv312\Scripts\python.exe scripts\blind_retrieval.py prepare
.\.venv312\Scripts\python.exe scripts\blind_retrieval.py predict
.\.venv312\Scripts\python.exe scripts\blind_retrieval.py score
.\.venv312\Scripts\python.exe scripts\blind_retrieval.py verify
```

预测只读取公开图片输入，答案文件只参与字节哈希校验，不解析内容。全部查询的两个策略完整排序保存后生成预测凭据；评分先验证冻结协议、数据和排序完整性，再创建开封凭据，最后首次解析答案。重复开封、候选缺失、重复查询、非有限分数、文件变化和标签进入公开输入均会被拒绝。

在开封前可运行 `scripts/verify_blind_predictions.py`，仅用保存的查询向量与图库逐条复算全部排序和分数，不解析答案、不再调用GPU编码。

本轮开封后已把440条记录及245个pair组登记至 `data/module2_consumed_holdouts/records.jsonl`。现有暴露审计会自动读取该目录；`consumed_exposure_snapshot.json` 保存开封后的新排除快照，初始 `exposure.json` 继续保持原样。

开封后，无论成绩提升或退化，数据集都已消耗。后续在其上看失败案例或做调参只能算开发；后续策略需要新的未曝光评测集。工程中断也保留领取凭据及失败痕迹，不通过删凭据重复抽样或选取最好的一次成绩。

## 正式三品类验收方案

以下是下一阶段方案，当前尚未建集或取得人工标签，不计为已完成。

1. 从未暴露商品组建立新的3C、服饰、家居候选池，先核对源商品ID、商品族或SKU、标题、URL、文件与像素哈希及近似图像。无法确认的同款族合并或剔除，不把同一商品换图分到开发与验收两边。
2. 预先固定60条独立查询作为首轮规模目标：每个品类10条中文文本、10条图片。图库初步目标为300件、每类100件。可先按元数据确认数量可行，最终数量和规则在任何验收模型推理前冻结；不依据成绩增删查询。
3. 独立评测人根据真实用户需求写查询与相关性标准，避开复制候选标题或看排名改写查询。图片查询排除自身及相同图片副本；若允许同款的其他实拍图，须预先写入标准。
4. 对冻结候选池完整标注二元相关性。按固定哈希打乱展示顺序，隐藏模型分数与排名。每对关系由真实人工判断，未判为null，无法判断记录原因；不同品类、模型低分或未进Top-K都不自动视为负例。两人独立标注并仲裁分歧作为目标流程，署名与来源声明不等同身份认证。
5. 固定最终模型与策略后保存完整排序，再由答案保管人开封。任何标签、商品族或人工选框答案不得用于自动ROI或排序参数。ROI局部查询可另建诊断子集，不用它替换更难的整图查询。
6. 两种查询模式分别报告Recall@10、Precision@10、完整mAP、NDCG@10、MRR、Hit@1及三个品类分项。Recall分母是该查询在冻结图库中的全部相关商品，Precision分母固定为10；零正例查询单列并报告占比，不能悄悄删除或令Recall=1。报告所用有效分母。
7. 原PDF的Recall@10≥70%、Precision@10≥60%只能在正式相关性协议下核对。先冻结模式汇总方式与是否另设子类门槛；不把同款任务的低正例数量造成的Precision上限当成PDF达标依据。
8. 测量实际服务接收请求到返回Top-N的端到端耗时，保留所有请求、样本数、P50/P95、最大值及超过5秒的比例。仅编码或CPU重排耗时不代替服务耗时；P95≤5秒不等于每次≤5秒。冷启动单独报告，并在正式协议里说明服务状态。

标注采用完整图库，避免仅给Top10打标导致Recall分母未知。人工未完成、独立性未证实、预测未冻结或协议有变动时，正式指标继续为空。当前独立同款集的正例是源身份关系，不是上述人工业务相关性，不能混用两者的精度分母和验收门槛。
