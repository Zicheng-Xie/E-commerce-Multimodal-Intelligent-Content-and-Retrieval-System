## 开发与验收的边界

历史服饰同款实验、新业务开发实验及独立heldout分别记录。**所有本轮成绩仅供内部开发，不能当作正式验收结果对外输出。** 当前对外进度文件中的`quality_metrics`和`formal_metrics`均为null，`goal_met`为false。

模型运行前检查商品ID、商品族、文件哈希、定向像素哈希及dHash近重复，预留heldout与开发数据的已记录重叠为0。检查使用预先保存的验收指纹，不读取验收图片；预留登记哈希保持不变，验收模型推理0。

运行输入仅含商品原标题、图像及查询无关的主体/外观描述，排除采样bucket、来源品类、AI相关性答案及评审理由。分组训练仍属于开发验证，不能替代独立heldout盲测。未知标签保留空值，不自动当作不相关。

本轮发现开发对照改善，但图片检索覆盖及召回目标尚未全部满足，候选保持实验状态，默认策略未升级。具体数值、分模式结果、扩容与策略收益的区分及失败案例统一留在[内部开发报告](../artifacts/module2_expanded_development/internal_report.md)。

## 运行新开发索引

使用既有`.venv312`和完整本地模型，无新依赖。以下命令用于开发演示，显式指定候选策略，不代表验收发布。

```powershell
.\.venv312\Scripts\python.exe scripts\retrieve_expanded_development.py --text "白色短袖T恤" --method public_evidence_soft --output artifacts\my_expanded_query
```

图片支持`--image`、`--roi x1 y1 x2 y2`，ROI为0到1的归一化坐标。可选策略为`global`、`region_title`、`semantic_blend`、`public_evidence_soft`、`balanced_logistic`、`hard_negative_ranknet`。每次使用新的输出目录。

```powershell
.\.venv312\Scripts\python.exe scripts\verify_expanded_development.py
.\.venv312\Scripts\python.exe scripts\report_expanded_development.py
```

复核及报告重建不运行GPU推理；已完成的索引和比较入口拒绝覆盖。

工程验证：217项测试、61个源文件mypy及本轮格式检查通过；216组完整排序重放通过，12个历史封存目录未变。
