# 模块二Precision提升当前结论

更新日期：2026年10月22日。

本轮已实测专用图像精排、前排保护、边界精排、困难负例RankNet与蒸馏、局部视觉注意力。当前没有方案同时达到Precision@10增加至少2个百分点和其他五项开发均值不退化的目标，原默认检索策略保持不变。

截图中独立同款集的Precision@10平均理论上限是43.25%，当前37.25%，最多剩余6个百分点。原因是每条查询的图库正例数量有限，而Precision@10固定除以10。不能通过减少K、换分母或修改旧相关性标签来声称原指标大幅提升。

在原开发集上，保留前两名加专用精排的Precision增益为1.54个百分点，其余五项均值未下降；但30对评分P95约13.87秒。保留前五名的十对边界精排增益为1.15个百分点，缓存评分分项P95约4.79秒；实际新图片命令包含模型切换等步骤为20.78秒，不能当作5秒服务达标。以上均为开发观察，不与截图分数跨数据集相减。

新增后续训练扩容：150个训练组、50个开发验证组；已跑通可训练注意力、实拍图适配和人工标签导入，仍未通过提升门槛。见 [后续训练进度](module2_training_progress.md)。

## 接下来重点

优先补充真实商品相关性标注与训练商品组，用困难负例训练精排，解决“语义相似但不相关”的混淆。正式商品相关性与当前严格同款属于不同任务，人工新标签必须独立保存；正式三品类验收仍按 [独立盲测规范](module2_blind_evaluation.md) 准备，不复用已开封集合。

全图库指标需要完整相关性标注。这个Top30开发包只能供训练和困难样本分析，不能用局部标注替代Recall分母。
