## 你负责的20%真实人工复核

从既有12,600条开发关系中，按查询及AI标签层冻结抽取2,520条，其中包含AI未判定项。抽样不使用检索排名或分数。用户已明确由本人复核，初始答案全空。

1. 用浏览器打开 `artifacts/module2_simple_baseline_20261105/human_audit/index.html`。
2. 共84批，每批30条。填写固定审核者姓名或代号，勾选本人独立判断。
3. 根据原图、原标题及查询的商品主体、用途、明确属性，选择1（相关）、0（不相关）或uncertain（证据不足），并填写理由。页面隐藏AI标签、分数和排序。
4. 每批及时导出CSV，保存到 `human_audit/answers/` 文件夹。同批修改后覆盖旧文件，不要保留重复副本。浏览器暂存不能代替导出备份。
5. 在项目根目录运行：

```bash
.venv-mac/bin/python scripts/simple_cycle_review.py score
```

评分器合并 `human_answers.csv` 和 `answers/*.csv`，拒绝未知任务、重复答案及缺少真实人类声明、姓名、时间、理由的记录。完整复核前，整体准确率保持空值；AI未判定、人工不确定分别统计。低于80%时需要扩充人工复核或重新标注，不把准确率直接乘到检索指标上冒充修正。80%门槛即使通过，也只是抽样中的一致率，不代表全部AI标签已经成为真值。

## 两轮盲测与新的验收保留集

两轮已用盲测的消耗登记不变；在当前评测角色配置中明确禁止训练、开发调参、再次推理和复用为未见测试。本轮仅读取消耗登记中的排除元数据，没有读取两轮盲测的图片、相关性标签、预测或指标。

新保留集位于 `artifacts/module2_final_acceptance_20261105/`：

| 状态 | 数量与条件 |
|---|---|
| 已冻结图库 | 300件，30细分类各10件 |
| 已冻结图片查询 | 30条，30细分类各1条 |

| 模型预测／语义预览 | 0／0 |

| 正式验收状态 | 尚未就绪；禁止开发、训练和提前模型推理，formal_metrics=null |

选择只依赖预先冻结的元数据顺序、下载有效性及图像指纹。网络限制导致的失败已归档，联网重试保持同一队列和排除规则。图像哈希及去重不能证明没有任何未记录的历史访问，也不能保证所有语义近重复均被发现。

`configs/evaluation_registry.json` 记录当前角色、人工复核指派及未来抽样排除快照；`require_data_access` 提供调用前的代码检查，本轮执行器另有冻结输入和源文件校验。这是工程流程保护，不是操作系统级访问控制；后续新增入口也必须执行相同检查。
