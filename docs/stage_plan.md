## 四项阶段产出

1. **标准化多模态实验数据集**：旧300件商品和180条服饰留档；新分类副本286件、服饰可用179条。仍需补齐新商品池及人工确认，不能混用新旧统计。
2. **中文文案生成基线系统**：v3已冻结提示词/模型/参数/代码/数据，来源冲突暂停、否定/SKU规则及预留集运行均已完成；独立人工质量评分待完成。
3. **多模态检索基线系统**：已有本地Qwen3-VL-Embedding-2B（BF16、batch=1）、300件商品2048维索引、CLI和HTML结果页；峰值PyTorch分配约4.02GiB，与生成模型交替使用显存。
4. **基线效果评测报告**：初测、扩展数据及 `copy_baseline_v3.md` 的90件文案运行/性能记录均已保存；新增 `mentor_feedback_adoption.md` 的同款量化、千图库性能与边界测试。三大品类相似款独立相关性指标和文案人工评分仍待完成。

导师建议采用范围、代码结构和证据见 [工程调整说明](mentor_feedback_adoption.md)。30条合成边界输入补充90件真实预留样本；1000张服饰副本是额外性能/同款开发数据，不替换已冻结的300件商品集。事实草稿与受控营销语句由新合同层分开返回，原v3四个冻结核心代码文件保持可校验。

当前优先顺序与本次代码、数据纠正见 [第二阶段纠正记录](stage2_corrections.md)：先补齐并冻结新的明确品类评测池，再重建对应实验和评审。已用于本次规则开发的旧预留样本只作回归/诊断，不能重复声明为未见盲测。

评审入口与最新工程交付见 [第二阶段评审流程](stage2_review_workflow.md)。已实际验证空评审不产生正式成绩；21个批次当前仍待真实填写。服饰可用版本位于 `data/stage2_fashion_clean_v1/`，旧180条副本不覆盖。

图文嵌入使用真正支持图像和文本的Qwen3-VL-Embedding-2B。`qwen3-embedding:0.6b` 和已有 `nomic-embed-text` 是文本嵌入，不作为图像编码器。Ollama继续用于生成；图文嵌入通过本地Transformers运行，权重位于原E盘模型根目录的external子目录。

检索评测按PDF定义：Recall@10 = Top10相关商品数 / 全部相关商品数；Precision@10 = Top10相关商品数 / 10。仅单图配单标题的自检不能代替真实相关性标注；不得用测试标签拼接查询内容后宣称检索达标。

第三阶段的微调、RAG、对比学习优化暂不开展。第四阶段的分割模型、局部定位、细粒度问答也不在本次范围；目前只转换已有标注。

官方模型参考：[Ollama Qwen3.5规格](https://ollama.com/library/qwen3.5/tags)、[Qwen3-VL-Embedding-2B](https://huggingface.co/Qwen/Qwen3-VL-Embedding-2B)。
